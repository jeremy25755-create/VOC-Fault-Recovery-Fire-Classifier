# Dataset

`Indoor_Fire_Except_Sensor0011.csv` was produced from the public Indoor Fire
Dataset by excluding sensor node 0011.

Source: Pascal Vorwerk, *Indoor Fire Dataset with Distributed Multi-Sensor
Nodes*, Mendeley Data, Version 1, 2023.
